# Dr. Anvar Xushvaqtov — plastik jarroh

Premium bir sahifali veb-sayt (HTML + CSS + JS, kutubxonasiz).

Ochish: `index.html` ni brauzerda oching yoki `python3 -m http.server`.

- `index.html` — tuzilma
- `style.css` — dizayn va animatsiyalar
- `main.js` — interaktivlik (tashxis yo'naltiruvchisi, tiklanish jadvali, forma)
- `img/` — rasmlar (shifokor fotosi o'z Instagram e'lonidan, qolganlari Unsplash namuna rasmlari)

Eslatma: sayt tibbiy maslahat o'rnini bosmaydi. Bemor fotosuratlari ishlatilmagan.
