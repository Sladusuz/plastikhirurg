# Dr. Anvar Xushvaqtov — plastik jarroh

Shifokorning o'z brendi (krem, oltin, to'q ko'k) va Instagram'dagi haqiqiy plakat/reels kadrlari asosidagi veb-sayt (HTML + CSS + JS, kutubxonasiz).
Telefonda pastki menyu, kompyuterda yon panel.

Ochish: `index.html` ni brauzerda oching yoki `python3 -m http.server`.

- `index.html` — ko'rinishlar: Bosh, Ishlar, Muolaja, Reja, Aloqa
- `style.css` — dizayn va animatsiyalar
- `main.js` — yo'naltirish, ishlar galereyasi (lightbox), muolajalar, tiklanish xaritasi, forma
- `img/real/` — shifokorning o'z Instagram sahifasidan olingan plakat va reels kadrlari (past aniqlikdagi skrinshotlar; asl fayllar bilan almashtirish tavsiya etiladi)

Eslatma: sayt tibbiy maslahat o'rnini bosmaydi.
